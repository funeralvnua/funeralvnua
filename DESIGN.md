# Дизайн-система — ritual.vn.ua

**Принципи:** стриманість · шанобливість · ясність · доступність (WCAG 2.2 AA)
**Підхід:** mobile-first · semantic HTML · progressive enhancement
**Дата:** 2026-04-29

---

## 1. Філософія

Ритуальна сфера — не місце для маркетингових прийомів. Користувач у горі, у стресі. Дизайн повинен:

- **Заспокоювати** — м'які тони, повітря, стриманий ритм.
- **Не відволікати** — мінімум анімацій, без каруселей, без поп-апів.
- **Викликати довіру** — реальні фото, чіткий NAP, видимий телефон, фото команди.
- **Бути швидким** — людина не може чекати завантаження. LCP < 2.0s.
- **Бути доступним** — велика типографіка для літніх користувачів (старша демографія).
- **Бути простим** — мінімум кліків до телефону/форми.

**Чого уникаємо:** червоних/яскравих кольорів (тривога), агресивних CTA («Купити!», «Замовити терміново»), таймерів, стокових фото, емоджі, важких ілюстрацій, decorative animations, parallax, autoplay-відео.

## 2. Дизайн-токени

### 2.1 Кольорова палітра

Налаштовується через CSS variables у `app/globals.css`. Tailwind v4 підтягує через `@theme`.

```css
:root {
  /* Surface — фони */
  --color-bg:           #f8f5f0;   /* основне тло (теплий пергамент) */
  --color-surface:      #ffffff;   /* картки, контейнери */
  --color-surface-alt:  #efeae1;   /* hover, секунд. блоки */
  --color-overlay:      rgba(20, 20, 20, 0.55);

  /* Ink — типографіка */
  --color-text:         #1a1a1a;   /* основний текст */
  --color-text-soft:    #4a4a4a;   /* second. текст, метадані */
  --color-text-muted:   #7a7a7a;   /* підказки, плейсхолдер */

  /* Brand — акценти */
  --color-primary:      #2c4a3e;   /* глибокий синьо-зелений (спокій) */
  --color-primary-700:  #1f3530;   /* hover */
  --color-primary-100:  #dde7e2;   /* tint, фон секцій */
  --color-accent:       #a8843d;   /* мутне золото (пам'ять, шана) */
  --color-accent-700:   #876a30;

  /* Semantic */
  --color-emergency:    #6b1f1f;   /* лише для sticky-call mobile */
  --color-success:      #2f6b4a;
  --color-warning:      #a3700f;
  --color-danger:       #8a1f1f;

  /* Lines */
  --color-border:       #d8cfbf;
  --color-border-soft:  #e6dfcf;
  --color-focus:        #2c4a3e;
}
```

**Контраст (WCAG):** усі пари `text/bg`, `text-soft/bg`, `accent/bg` перевірено ≥4.5:1.

**Темна тема:** не реалізовуємо у MVP (нерелевантно для ринку). Можна додати пізніше.

### 2.2 Типографіка

**Шрифти:** `next/font/google` — self-hosted, без CLS.

```ts
// app/fonts.ts
import { Cormorant_Garamond, Manrope } from 'next/font/google';

export const heading = Cormorant_Garamond({
  subsets: ['cyrillic', 'latin'],
  weight: ['500', '600'],
  style: ['normal', 'italic'],
  variable: '--font-heading',
  display: 'swap',
});

export const body = Manrope({
  subsets: ['cyrillic', 'latin'],
  weight: ['400', '500', '600', '700'],
  variable: '--font-body',
  display: 'swap',
});
```

**Type scale (mobile → desktop):**

| Роль | Font | Size mobile | Size desktop | Line-height | Weight |
|---|---|---|---|---|---|
| Display (Hero H1) | heading | 36px | 56px | 1.1 | 600 |
| H1 | heading | 30px | 44px | 1.15 | 600 |
| H2 | heading | 26px | 36px | 1.2 | 500 |
| H3 | heading | 22px | 28px | 1.25 | 600 (Manrope!) |
| Lead | body | 18px | 20px | 1.5 | 400 |
| Body | body | 17px | 17px | 1.65 | 400 |
| Small | body | 14px | 14px | 1.55 | 500 |
| Caption | body | 12px | 12px | 1.5 | 600 + uppercase + letter-spacing 0.05em |

> H3 використовує **Manrope** (sans), щоб прибрати «вилку трьох серифів» і додати ритм. H1/H2 — серифні (Cormorant).

**Українська типографіка — нюанси:**
- Pang і дзвінкий «Ї»/«Є»/«Ґ» — Cormorant їх рендерить коректно.
- Не використовувати tabular-nums у заголовках (для серифа виглядає неприродно).
- Апостроф — типографічний `'` (U+2019), не прямий ASCII.
- Тире — `—` (em-dash, U+2014) між клаузами.
- Лапки — `«»` для українського, не `""`.

### 2.3 Spacing (Tailwind стандарт + 4px base)

Використовуємо стандартні `space-1..space-32`. Ключові ритми:

| Token | px | Use |
|---|---|---|
| 1 | 4 | inline gaps |
| 2 | 8 | компактні елементи |
| 3 | 12 | between text + icon |
| 4 | 16 | base |
| 6 | 24 | між карток |
| 8 | 32 | між блоків |
| 12 | 48 | між секцій (mobile) |
| 16 | 64 | між секцій (desktop) |
| 24 | 96 | hero padding desktop |

### 2.4 Радіуси

```css
--radius-xl: 24px;
--radius-full: 9999px;
```

Кнопки — `--radius-md`. Картки — `--radius-lg`. Чіпи/таги — `--radius-full`.

### 2.5 Тіні

```css

--shadow-sm: 0 2px 8px rgba(20, 20, 20, 0.06);
```

## 4. Компонентна бібліотека

Усі — на основі **Radix UI** + Tailwind. Генеруються через `class-variance-authority` (cva) для варіантів.

### 4.1 Button

| Variant | Use |
|---|---|
| `primary` | головний CTA — викликати агента, надіслати форму. Колір: bg `--color-primary`, text white. |
| `accent` | другорядний CTA — переглянути ціни. Колір: bg `--color-accent`, text white. |
| `outline` | тонке обрамлення `--color-primary`, прозоре тло. |
| `ghost` | без обрамлення, для tertiary дій. |
| `emergency` | лише на mobile sticky-bar. Колір: bg `--color-emergency`, text white, weight 600. |

| Size | Padding | Font |
|---|---|---|
| `sm` | `px-4 py-2` | 14px |
| `md` | `px-5 py-3` | 16px |
| `lg` | `px-6 py-4` | 17px |

**Стани:** default · hover (затемнення -8%) · focus (`outline: 2px solid focus`) · disabled (opacity 0.45).
**Loading-state:** замість тексту — `Loader2` з anim-spin.
**Touch-target:** мінімум 44×44px.

### 4.2 Input / Textarea

```
┌─────────────────────────────┐
│ Ваше ім'я *                  │
│ ┌─────────────────────────┐ │
│ │                         │ │
│ └─────────────────────────┘ │
│ Помилка / підказка           │
└─────────────────────────────┘
```

**Стани:** default · focus (border `--color-focus`, shadow soft) · error (border `--color-danger`, помилка червоним) · disabled.
**Розмір:** висота 48px (touch-friendly), font 17px.
**Лейбли:** завжди видимі (не floating placeholder).
**Required:** червона зірочка `*` після назви.

### 4.3 Card

Базовий контейнер для послуг, відгуків, постів блогу.

```
┌──────────────────────────┐
│  [Icon 24px]             │
│                          │
│  Назва послуги (H3)      │
│  Короткий опис (body)    │
│                          │
│  Дізнатись більше →      │
└──────────────────────────┘
```

- bg: `--color-surface`
- padding: 24px (mobile), 32px (desktop)
- radius: `--radius-lg`
- border: `1px solid --color-border-soft`
- hover: трансформація border на `--color-primary-100`, shadow-md, без translate

### 4.4 Accordion (FAQ)

Нативний `<details><summary>` з кастомним стилем. Без JS обов'язкового.

```
▾ Питання?                  (summary)
   Розгорнута відповідь.   (body)
```

Schema FAQPage прокидається у DOM незалежно від відкритого стану.

### 4.5 Tabs

Radix Tabs. Використання: блок Service Area, прайс-пакети.

### 4.6 Dialog (Modal)

Radix Dialog. Лише для:
- Виклик форми «Передзвоніть мені» з sticky-bar.
- Розгорнути карту локацій.

Немає поп-апів-перехоплювачів («Зачекайте! Залиште номер»).

### 4.7 Breadcrumbs

```
Головна / Послуги / Послуги моргу
```

- Schema BreadcrumbList.
- Sep: `/` (текстовий).
- Поточна сторінка — `aria-current="page"` без посилання.

### 4.8 Phone Link Component

```tsx
<PhoneLink number="+380677107110" tracking="hero" />
// → <a href="tel:+380677107110" onClick={trackEvent}>(067) 710 17 10</a>
```

GA4-event: `phone_click` з полем `source`.

## 7. Анімації / Motion

### 7.1 Принципи

- **Subtle** — переходи 200ms, fades, без bounce/spring.
- **Purposeful** — анімація має мету (відгук на дію, не декорація).
- **Reduced motion** — повага до `prefers-reduced-motion: reduce` обов'язкова.

### 7.2 Конкретно

| Подія | Анімація |
|---|---|
| Hover на картці | border-color 200ms ease, shadow 200ms |
| Open accordion | height auto, 250ms ease-out |
| Open modal | fade-in backdrop 200ms, scale 0.95→1 + fade-in dialog 250ms |
| Sticky-bar appear | slide-up 300ms на page load |
| Form submit success | fade in toast |

**Чого не робимо:** parallax, marquee, autoplay-carousel, scroll-jacking, gradient-shift.

### 7.3 Бібліотека

Базові переходи — Tailwind `transition-*`. Складніше — Framer Motion (опційно, лише якщо знадобиться).

## 8. Доступність (a11y)

### 8.1 Стандарт — WCAG 2.2 AA

**Контраст:**
- text/bg ≥ 4.5:1 (звичайний текст)
- large text (≥18px / 14px+bold) ≥ 3:1
- UI components ≥ 3:1

**Перевірка:** Lighthouse + axe DevTools. CI-тест на старті.

### 8.2 Семантичний HTML

- `<header>`, `<nav>`, `<main>`, `<aside>`, `<footer>`, `<article>`, `<section>` — за змістом.
- Один `<h1>` на сторінку.
- Heading-ієрархія без пропусків (H2 → H3, не H2 → H4).
- `<button>` для дій, `<a>` для навігації.
- Форми: `<label>` зі зв'язком `for/id`, `aria-describedby` для помилок.
- Списки локацій — `<ul>` (не `<div>` сітка).

### 8.3 Клавіатура

- Усі інтерактивні елементи tab-able.
- Focus-стилі видимі (outline 2px primary).
- Modal: focus trap + Escape.
- Skip-link «До основного контенту».

### 8.4 Screen reader

- `aria-label` на іконкових кнопках («Закрити», «Меню»).
- `aria-live="polite"` для toast-повідомлень.
- `aria-current="page"` у breadcrumbs / nav.
- Telegram/Viber/телефон: `aria-label` з повним номером.

### 8.5 Reduced motion

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}
```

### 8.6 Velikiy chyfta-ankha (large text option)

Не обов'язково для MVP, але:
- Базовий font 17px (вже комфортно для літніх).
- `rem`-based spacing — масштабується з налаштуваннями браузера.

## 9. Зображення та фото

### 9.1 Принципи

- **Реальні фото** > сток. Сток допустимий лише для абстрактних блоків (не для команди/офісів).
- Темні віньєтки на hero-фото (для читабельності тексту).
- Усі — `next/image` з AVIF/WebP fallback.
- `loading="lazy"` за замовч., hero — `priority`.
- Завжди `alt` (з природним описом, не stuffing).

### 9.2 Тони

- Низький контраст, тепла тонізація (трохи sepia / warmth).
- Немає різких тіней.
- Природне освітлення.
- Уникати яскравих кольорів у фото (кольорові квіти на стоці — ні).

### 9.3 Розміри (orient.)

| Контекст | Розмір (max) |
|---|---|
| Hero | 1920×900 (desktop) / 800×600 (mobile) |
| Картка послуги | 600×400 |
| Відгук-аватар | 120×120 |
| Команда | 480×600 |
| Інтер'єр зали | 1200×800 |

## 11. Стани мови (i18n UI)

### 11.1 Перемикач

```
┌─────────────┐
│  uk · ru    │      ← компактна форма
└─────────────┘
```

- Активна локаль — bold, темніша.
- Inactive — soft text + underline on hover.
- Зберігає поточний slug при перемиканні.
- `cookie: NEXT_LOCALE` авто-set через next-intl.

### 11.2 Україномовний vs російськомовний контент

- Дизайн ідентичний.
- Перевірити: довжина перекладу — російські слова часто на 10–20% довші, тому кнопки/картки повинні бути flexible.

## 13. Чек-лист дизайну перед розробкою

- [ ] Палітра затверджена (можливо адаптувати під фірмові кольори служби)
- [ ] Шрифти затверджені (Cormorant Garamond + Manrope)
- [ ] Реальні фото зібрано (зали, команда, транспорт) — мінімум 30 шт.
- [ ] Лого у форматі SVG + favicon (16/32/180/512)
- [ ] OG-image — статична + шаблон для динамічної (`opengraph-image.tsx`)
- [ ] Перевірено всі стани форм (idle/error/loading/success)
- [ ] Перевірено мобільну зону тач-таргетів (≥44px)
- [ ] Перевірено доступність кольорів через WebAIM Contrast Checker
- [ ] Перевірено reduced motion preference
- [ ] Перевірено keyboard navigation на ключових сторінках
- [ ] Sticky-bar не перекриває важливий контент
- [ ] Перевірено довжину текстів у обох локалях (uk + ru)

## 14. Що залишається

- **Logo design** — окремо (потрібна графічна робота). До затвердження логотипу — текстовий placeholder.
- **Реальні фото** — фотосесія з боку служби.
- **Microcopy** — фінальні тексти кнопок/підказок узгоджуються з замовником.
- **Figma-макети** — опційно, можна йти прямо в код (Tailwind + компонентна бібліотека ≈ design system).
